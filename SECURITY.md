# Security

请不要在公开 Issue 里报告安全问题。请通过 GitHub 的私密漏洞报告提交：
仓库页面 → **Security** → **Report a vulnerability**。

Please do not report security problems in public issues. Use GitHub's private vulnerability
reporting instead: repository page → **Security** → **Report a vulnerability**.

请尽量附上 / Please include:

- 受影响的版本与系统 / affected version and operating system;
- 复现步骤 / steps to reproduce;
- 可能的影响 / the impact you expect.

我们会尽快回复，修复发布前请不要公开细节。
We will reply as soon as we can; please keep details private until a fix is released.

范围 / Scope：Pi Desktop 本身（主进程、渲染进程、插件宿主、手机网关、更新与引擎下载）。
Claude Code、Codex 与 Pi 命令行程序本身的问题请报告给它们各自的维护者。
Problems in the Claude Code, Codex or Pi programs themselves belong with their maintainers.
